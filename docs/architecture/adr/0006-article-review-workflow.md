# ADR 0006：文章审核流

## 状态

已接受，第一阶段实施中。

## 决策

普通用户创建公开文章时不能直接发布，必须经过管理员审核。

```text
DRAFT
→ PENDING_REVIEW
→ PUBLISHED

PENDING_REVIEW
→ REJECTED
→ DRAFT
```

管理员可以直接发布，也可以审核、驳回、下架任意文章。

## 第一阶段约束

- 提交审核后，作者不能继续编辑，必须先撤回。
- 已发布文章，普通用户不能直接编辑，必须先撤回。
- 私密文章不进入审核，可以直接发布。
- 公开文章只返回 `PUBLISHED + PUBLIC`。
- 现有已发布文章迁移为 `PUBLISHED`，不重新审核。

## 后续升级

引入文章修订版本：

```text
Article
└── ArticleRevision
    ├── PUBLISHED 版本
    └── PENDING_REVIEW 版本
```

目标：

- 已发布内容保持在线。
- 用户编辑生成待审核修订，不立即覆盖线上。
- 审核通过后原子替换当前发布版本。
- 支持审核快照、回滚和审核记录。

该升级不在第一阶段实施。
