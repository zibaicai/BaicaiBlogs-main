# ADR-0001：Admin 控制台面向所有注册用户

- 状态：已采纳
- 日期：2026-11-03

## 背景

项目是社区网站。早期把 Admin 控制台当成管理员专用后台，导致普通用户登录后访问管理员概览接口被 403，并被前端当成登录失效强制退出。

## 决策

```text
Admin 控制台 = 所有注册用户的控制台
USER / ADMIN / SUPER_ADMIN 均可登录
角色决定工作区和管理能力
```

## 后果

- 登录阶段不拒绝 USER。
- 控制台首页按角色选择数据源。
- 普通用户只请求自己的资源接口。
- 管理员专属路由需要单独守卫。

## 替代方案

- 普通用户禁止登录控制台：不符合社区定位。
- 普通用户登录后只看静态页：无法管理自己的内容。
