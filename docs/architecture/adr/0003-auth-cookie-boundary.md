# ADR-0003：认证 Cookie 与跨子域边界

- 状态：已采纳，需继续收敛
- 日期：2026-11-03

## 背景

C 端 `/articles/manage` 需要识别管理员，曾将普通登录 Cookie `BC_TOKEN` 扩展到 `.zibaicai.cn`。

这会让普通用户登录覆盖后台子域登录态，造成角色混乱和强制退出。

## 决策

```text
BC_TOKEN        普通登录态，按站点隔离
BC_ADMIN_TOKEN  管理员跨子域能力
或短期签名预览 token
```

管理员跨子域能力不能复用普通用户 Cookie。

## 后果

- 普通用户登录不影响管理员后台。
- C 端管理目录需要独立管理员凭证。
- Cookie 清理和退出需要分别处理。
- 不再把普通用户 token 同时当作管理员凭证。
