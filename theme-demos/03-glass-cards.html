玻璃卡片的层次：四种做法并排看

背景在缓慢流动（这是水面的替身）。重点观察：当亮色区域扫到卡片边缘时，哪一张的"边界"会消失。 拖动滑块可以直接感受 tint / blur / 边缘强度的关系。

A · 只有 border

用一条描边定义边界

静态背景上够用。但描边的可见性依赖"与背景的对比度"，而背景在流动——亮部扫过来时，这条线会凭空消失。

B · 只有 box-shadow

用投影定义存在

投影表达的是"离背景的距离"，不是"边界"。一块半透玻璃挂一条重阴影，看起来像悬浮的黑色板子压在画面上。

C · 四层边缘（推荐）

顶边亮 + 底边暗 + 内描边

层叠的两条 inset 做出倒角：亮边负责在深色背景上可见，暗边负责在亮色水波上可见。任意背景下总有一条线成立。

D · 四层 + 文字底板

边界归边界，可读性归底板

卡片边缘保持高透（负责观感），文字背后垫一块更实的窄板（负责可读性）。比整张卡片加不透明度更像真实材质。

结论：浮层（弹窗、下拉、hover 抬起的卡片）必须换成不透明底板（alpha ≥ 0.85）， 高透只能用在"同一平面"的卡片上。

可调参数建议做成令牌： --glass-tint / --glass-blur / --glass-edge / --glass-shade。 水主题和樱花主题只要改这四个值，组件层一行都不用动。
