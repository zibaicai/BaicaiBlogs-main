主题样板 · 索引

四个独立文件，双击即可在浏览器打开，全部零依赖、离线可用。 每个文件右下角都有控制面板，可以单独开关其中某一层效果，方便判断"是哪一层在起作用"。

SAMPLE 01
水波纹主题 · 完整预览
全屏水面（解析环形波 + 折射 + 色散 + 镜面高光）+ 雨丝 + 点击涟漪 + 毛玻璃卡片。面板可分别关掉雨、涟漪、遮罩、毛玻璃，单独观察每一层。
WebGL点击涟漪雨backdrop-filter
SAMPLE 02
樱花主题 · 夜樱 / 日樱 / 白樱
点精灵程序化花瓣 + 欧拉角旋转 + 逐顶点光照 + 景深裁剪 + 泛光。点击迸发花瓣。三种配色共用同一套着色器（颜色全部走 uniform），可切换花瓣层在卡片前 / 后。
WebGL点精灵bloom可换配色
SAMPLE 03
玻璃卡片层次 · 四种做法并排
只有 border / 只有 shadow / 四层边缘 / 四层 + 文字底板，背景是流动的，专门用来验证"描边会不会在亮部扫过时消失"。含叠卡翻车演示与可调令牌。
纯 CSS四层边缘令牌
SAMPLE 04
点击涟漪 · 轻量浮层（无 WebGL）
纯 Canvas2D 的点击涟漪，叠在浅色博客页面上，不需要卡片变透明。可以切换混合模式，直观看到"光"和"水"的差别，以及与深色页面的兼容性。
Canvas2D零依赖混合模式
SAMPLE 05
樱花背景层 · 真 alpha（第一步：无泛光）
把原版樱花搬成透明图层，叠在你的真实页面截图上看合成效果。花瓣形状、颜色、深度排序与原版一致，只改了输出方式。可切换日/夜背景、蒙版强度、密度，以及"远景变暗"（原版行为）对照。
WebGL真 alpha延迟加载
